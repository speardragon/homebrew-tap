# speardragon/homebrew-tap

Homebrew casks for [herdr-bot](https://github.com/speardragon/herdr-bot).

```sh
brew install --cask speardragon/tap/herdr-bot
```

herdr-bot updates itself from its app menu (**herdr-bot → Check for Updates…**). `brew upgrade --cask herdr-bot`
works too.

The cask follows herdr-bot's releases on its own: a workflow checks for a new release every hour.
